# 🐭 鼠哥的 Python 学院 🐿️

> **由 鼠哥（ndshuge）组织发起，拉里·佩奇 协助开发**

以马瑟斯《Python 编程：从入门到实践（第 3 版）》为蓝本的交互式 Python 学习学院。讲义、练习、代码判题、章节考试、错题本、问答批改一条龙，**打开网页就能学，不用装任何环境**。

## 🚀 使用链接

👉 **https://ndshuge.github.io/ndshuge-python-academy/?v=3**

手机、电脑、平板直接打开就能用。注册一个账号，进度自动云端同步，换设备接着学。

> 💡 若打开后界面不是最新版（浏览器缓存了旧页面），在网址末尾加 `?v=3`（版本号会随更新递增）即可强制加载新版；或分享板块复制链接（自动带版本号）。

## ✨ 功能

- **📖 课程讲义**：11 周计划、五大战役，从 print 到类
- **💻 代码练习**：浏览器内直接跑 Python（Pyodide 运行时），即时判题
- **📝 章节考试**：每章小卷，全对通关
- **❌ 错题本**：做错的题自动收集，订正归档
- **🏆 荣誉墙**：军衔（终端学徒 → Python 大师）+ 徽章收集
- **🔐 账号系统**：用户名 + 头像注册，找回密码，改用户名/头像/邮箱/密码
- **☁️ 多设备同步**：进度云端保存，登录即合并两端数据（取并集，不丢进度）
- **🏆 学习排行榜**：全班进度实时排名，前三名奖牌
- **💬 给作者留言**：实名留言，建议直接送达作者

## 🛠 技术

- 单文件 HTML（样式脚本全内嵌，零依赖）
- Supabase（Auth + PostgreSQL + RLS 行级安全）
- Pyodide（WebAssembly 版 Python，浏览器里跑代码）
- GitHub Pages 部署
