# 拉里·佩奇的 Python 学院

以马瑟斯《Python编程：从入门到实践》（第 3 版）为蓝本的交互式 Python 学习网页。

## 怎么用

直接访问本仓库的 GitHub Pages 网址，在浏览器里打开即可开始学习，无需下载、无需安装。

## 功能

- 11 周学习计划，勾选进度
- 20 章课程体系（章节陆续补全中）
- **浏览器内直接写代码、运行、即时判题**（内置 Python 运行时，无需本地环境）
- 选择题即时批改
- 问答批改
- 学习足迹记录
- 徽章系统

## 技术说明

- 单文件 HTML（所有样式与脚本内嵌），仅代码运行依赖 Pyodide（WebAssembly 版 Python，从 CDN 加载，首次加载稍慢，之后走浏览器缓存）
- 学习进度保存在各学习者自己的浏览器 localStorage 中，互不影响
- 侧边栏有「导出进度」「导入进度」按钮，可自助备份或迁移进度
