# 🐍 拉里·佩奇的 Python 学院

> 以马瑟斯《Python编程：从入门到实践》（第 3 版）为蓝本的交互式 Python 学习网页。
> **打开即学，无需安装，浏览器里直接写代码、跑代码、判题。**

## 🚀 怎么用

- **同学访问链接**：<https://ndshuge-cloud.github.io/larry-page-python-academy/>
- 或下载 `index.html` 本地双击打开（联网加载 Python 运行时后即可使用）

## ✨ 功能

- 🗺️ **11 周学习计划**：五大战役，课时勾选，徽章自动解锁
- 📖 **20 章课程体系**：11 章全量讲义 + 3 大项目路线图；每章配导师故事、知识地图、易错点、随堂练习、章节考试、导师提问
- ⌨️ **浏览器内写代码**：内置 Pyodide（WebAssembly Python 运行时）+ CodeMirror 编辑器（语法高亮、行号、代码折叠、括号匹配、Ctrl+Enter 直接运行、命令面板）
- ⚡ **即时判题**：110+ 道练习（54 道代码题，运行输出自动比对）+ 66 道考试题
- 🏆 **荣誉墙**：称号阶梯（终端学徒 → Python 大师）、徽章墙、导师名人堂（学完章节点亮导师资料卡）
- 📊 **进度管理**：导出/导入/清空（清空需输入确认词），错题本、已订正、学习足迹、问答批改
- 🧑‍💻 **导师人设**：拉里·佩奇（Google 联合创始人）化身导师，每章配一位 IT 史/数学史名人故事

## 🛠️ 技术说明

- 单文件 HTML，样式脚本全内嵌，无构建步骤
- **Pyodide**（WebAssembly Python 运行时）从 CDN 加载
- **CodeMirror 5** 编辑器 + Python 模式
- 学习进度存各学习者浏览器 localStorage，互不影响，可导出迁移
